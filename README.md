## 🎯 الفكرة

أنت وصاحبك عندك **140 يوم ستريك** وعايزين توصلوا **600 يوم**.  
المشكلة: صاحبك في الجيش، وإنت ممكن ميكونش معاك نت.  
الحل: **بوت ذكي** بيدير الحسابين ويحافظ على الاستريك بدالكم.

### المنطق الذكي:
```
كل يوم 11:45 PM ← البوت يفتح المحادثة
  ├─ الاتنين بعتوا ← 🟢 ساكت (ميتدخلش)
  ├─ واحد بس بعت ← 🔵 يبعت بدل التاني
  └─ ولا واحد بعت ← 🔴 يبعت من الاتنين
```

### إيه اللي بيميزه:
- ✅ **ذكي**: مش بيدخل غير لما حد ينسى (مش بيبعت كل يوم عالفاضي)
- ✅ **مجاني 100%**: GitHub Actions + Render Free Tier
- ✅ **Dashboard لكل حساب**: كل واحد يدخل ب TikTok بتاعه ويظبط إعداداته
- ✅ **رسايل مخصصة**: عشوائي، ثابت، أو من اختيارك
- ✅ **تشغيل يدوي**: تقدر تشغله من الـ Dashboard في أي وقت

## 🔧 التسطيب خطوة بخطوة

### 1. تحميل المشروع

```bash
# نسخ المشروع
git clone https://github.com/YOUR_USERNAME/tiktok-streak-bot.git
cd tiktok-streak-bot
```

**أو** حمل الملفات ZIP من الرابط وافتحها.

### 2. تركيب المكتبات

افتح **Terminal / CMD / PowerShell** في مجلد المشروع:

```bash
pip install -r requirements.txt
playwright install chromium
```

**تأكد من نجاح التسطيب**:
```bash
pytest tests/ -v -k "test_requirements"
```
> ✅ لازم يظهر `PASSED`

### 3. الرفع على GitHub

**الطريقة السهلة (السكريبت):**
```bash
python deploy.py
```
ويدخلك خطوة بخطوة.

**الطريقة اليدوية:**
1. اعمل Repository جديد على GitHub
2. ارفع كل الملفات:
```bash
git init
git add .
git commit -m "Initial commit - TikTok Streak Bot"
git remote add origin https://github.com/YOUR_USERNAME/tiktok-streak-bot.git
git push -u origin main
```
3. روح على **Settings > Secrets and variables > Actions**
4. اضف `New repository secret`:
   - **Name:** `ENCRYPTION_PASSWORD`
   - **Secret:** (نفس كلمة السر اللي دخلتها في setup_login.py)

**تأكد من نجاح الخطوة:**
```bash
pytest tests/ -v -k "test_workflow or test_deployment"
```
> ✅ لازم تظهر `PASSED`

### 4. تفعيل GitHub Actions

1. روح على **Actions** tab في الـ Repository
2. هتلاقي `TikTok Streak Bot` في الشمال
3. اضغط **Enable** (لو مش مفعل)
4. اضغط **Run workflow** عشان تختبر:
   ```
   Workflow: TikTok Streak Bot
   Branch: main
   ```
5. استنى 2-3 دقايق، لو ظهر ✅ أخضر يبقى شغال!

### 5. تشغيل Dashboard على Render

1. اعمل حساب على https://render.com (مجاني)
2. اضغط **New +** > **Web Service**
3. اختار **Connect GitHub repository** واختار tiktok-streak-bot
4. ضبط الإعدادات:
   ```
   Name: tiktok-streak-bot (أو أي اسم)
   Runtime: Python 3
   Build Command: pip install -r requirements.txt
   Start Command: python server.py
   ```
5. اضف Environment Variables:
   ```
   FLASK_SECRET_KEY = (اكتب أي حروف عشوائية)
   GITHUB_TOKEN = (GitHub Personal Access Token)
   GITHUB_REPO = YOUR_USERNAME/tiktok-streak-bot
   ENCRYPTION_PASSWORD = (نفس اللي في GitHub Secrets)
   ```
6. اضغط **Create Web Service**
7. استنى 2-3 دقايق، هتاخد رابط زي:
   ```
   https://tiktok-streak-bot.onrender.com
   ```
8. افتح الرابط وجرب تسجيل الدخول!

### 6. إدخال بيانات التيكتوك من Dashboard

لأول مرة تفتح الداشبورد، هتوديك على صفحة **الإعداد الأولي (Setup)**:

1. افتح رابط الداشبورد (https://tiktok-streak-bot.onrender.com)
2. هتظهر صفحة الإعداد الأولي مباشرة
3. أدخل بيانات **الحسابين** (أنت وصاحبك):
   - **Account A** ← TikTok username + password + Dashboard password
   - **Account B** ← TikTok username + password + Dashboard password
4. اضغط **حفظ الإعدادات**
5. البيانات بتتنشفَر وتتخزن في GitHub Repository
6. بعد كدا هتتوجه لصفحة تسجيل الدخول

**تسجيل الدخول بعد الإعداد:**
- TikTok username بتاعك + كلمة سر الداشبورد (اللي حطيتها في الإعداد)
- كل واحد يدخل ويشوف تحكمات حسابه بس

> 💡 **مفيش حاجة اسمه setup_login.py دلوقتي** — كل حاجة من الداشبورد!

## ❓ حل المشاكل

### ❌ "Login failed" (فشل تسجيل الدخول)
- تأكد من صحة يوزر/باسوورد التيكتوك
- جرب تفتح **Settings** في الداشبورد وتحدث الباسوورد
- ممكن TikTok طلب CAPTCHA (بيحتاج متصفح يدوي)

### ❌ "ENCRYPTION_PASSWORD not set"
- ضيف الـ Secret في GitHub:
  **Settings > Secrets > Actions > New secret**
- ونفس القيمة في Render:
  **Dashboard > Environment Variables**

### ❌ GitHub Action بيفشأل
- افتح الـ Action وشوف الـ logs
- غالبًا مشكلة في الكوكيز أو الـ Playwright
- جرب تعمل `Run workflow` تاني

### ❌ Dashboard مش شغال
- اتأكد إن الـ Web Service على Render شغال (Status: Live)
- شوف الـ logs بتاع Render
- اتأكد من Environment Variables

### ❌ البوت مش بيكتشف إن أنا بعت
- TikTok أحيانًا بيغير HTML structure
- دا مش مشكلة كبيرة: البوت هيبعت برضه (أحسن ما الاستريك يكسر)

### ❌ عايز أحدث بيانات التيكتوك
- افتح الداشبورد
- روح على **الإعدادات (Settings)**
- غير الباسوورد واحفظ
